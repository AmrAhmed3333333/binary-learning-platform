# منصة مختبر النظام الثنائي (Binary Lab Platform)

منصة تعليمية رقمية تفاعلية مصممة خصيصاً باللغة العربية لطلاب **الصف الأول الثانوي**، تهدف إلى تبسيط مفاهيم النظام الثنائي، وطرق التحويل بين النظم العددية، ووحدات تخزين البيانات وفقاً لمقرر تكنولوجيا المعلومات والاتصالات (ICT) - الصفحات 62 إلى 67.

---

## 🎯 الفئة المستهدفة

* **الطلاب:** طلاب الصف الأول الثانوي الراغبون في فهم أساسيات النظم الثنائية وتطبيقها عملياً.
* **المعلمون:** معلمو مادة تكنولوجيا المعلومات والاتصالات الباحثون عن أدوات صفية تفاعلية وخطط حصص جاهزة.

---

## ✨ المزايا المنفذة والمخطط لها

### المنفذة فعلياً:

1. **شريط التنقل والتذييل الاحترافي:** واجهة متجاوبة تدعم اللغة العربية (RTL) مع إمكانية الوصول السريع لكافة أقسام المنصة.
2. **مستكشف الخانات الثنائية التفاعلي:** محاكي بصري لـ 8 بتات يوضح الأوزان المكانية (القوى $2^n$) وعمليات الجمع خطوة بخطوة.
3. **مختبر التحويل الرياضي المتقدم:** أداة للتحويل من عشري إلى ثنائي (عبر القسمة المتكررة) ومن ثنائي إلى عشري (عبر جمع الأوزان) مع تفصيل خطوات الحل.
4. **مستكشف البتات، البايت، ووحدات التخزين:** محاكي لاحتمالات الأسس ($2^n$) وحاسبة للتحويل بين الوحدات (Byte, KB, MB, GB, TB) باصطلاح $1024$.
5. **مستعرض الدرس الشامل:** عرض منظم لأقسام المنهج، الأمثلة، التصورات الشائعة الخاطئة، وأسئلة التحقق السريعة.
6. **مركز التدريب والتقييم الذاتي:** اختبار تفاعلي متدرج يعرض سؤالاً واحداً في كل مرة مع تغذية راجعة مفصلة وحساب للنتيجة النهائية.
7. **أداة معلم المادة (وضع المعلم):** دليل صفي متكامل يضم أهداف التعلم، خطة حصة مقترحة لمدة 45 دقيقة، أسئلة نقاش، أمثلة للسبورة، وأداة طباعة نظيفة لخطة الحصة.

### المخطط لها (مستقبلاً):

* إضافة مستويات تحدي متقدمة لعمليات الجمع الثنائي الحسابية.
* دعم حفظ نتائج الطلاب عبر حسابات محلية متقدمة.

---

## 🛠️ التقنيات المستخدمة

* **الإطار البرمجي:** Next.js (App Router).
* **مكتبة واجهة المستخدم:** React (JavaScript / JSX - **بدون TypeScript**).
* **التنسيق والرسوم:** Tailwind CSS v4.
* **الأيقونات:** Lucide React.
* **الاتجاه:** RTL (من اليمين إلى اليسار).

---

## ⚙️ متطلبات التشغيل

* بيئة تشغيل **Node.js** (الإصدار 18.x أو أحدث موصى به).
* مدير الحزم **npm** (أو yarn / pnpm).

---

## 🚀 أوامر التثبيت والتشغيل والبناء والفحص

1. **تثبيت الحزم والاعتماديات:**
```bash
npm install

```


2. **تشغيل خادم التطوير المحلي:**
```bash
npm run dev

```

3. **بناء المشروع للإنتاج (Production Build):**
```bash
npm run build

```


4. **تشغيل فحص الأكواد (Linting):**
```bash

```

## 📝 طريقة إضافة قسم تعليمي جديد إلى `src/data/lesson.js`

لإضافة قسم جديد إلى المنهج، افتح ملف `src/data/lesson.js` وأضف كائنًا جديدًا مصفوفة `sections` بالشكل التالي:

```javascript
{
  id: "section-new",
  title: "عنوان القسم الجديد",
  page: "صفحة الكتاب المرتبطة",
  simpleExplanation: "شرح مبسط ومباشر يناسب طلاب الصف الأول الثانوي.",
  correctExample: "مثال توضيحي أو تناظري/رقمي.",
  commonMisconception: "تنبيه حول تصور خاطئ شائع لتجنبه.",
  quickCheckQuestion: {
    question: "سؤال تحقق سريع حول القسم؟",
    options: ["الخيار الأول", "الخيار الثاني", "الخيار الثالث", "الخيار الرابع"],
    correctAnswerIndex: 0,
    explanation: "تفسير سبب صحة الإجابة."
  }
}

```

---

## ❓ طريقة إضافة سؤال جديد للاختبارات

لإضافة أسئلة تدريبية جديدة لمركز التقييم، توجه إلى قسم `exercises` داخل ملف `src/data/lesson.js` وأضف السؤال حسب نوعه:

* **اختيار من متعدد (`multipleChoice`):**
```javascript
{
  id: "mc-new",
  question: "نص السؤال هنا؟",
  options: ["أ", "ب", "ج", "د"],
  correctAnswer: 0, // فهرس الإجابة الصحيحة
  explanation: "تفسير الإجابة الصحيحة."
}

```


* **صح أو خطأ (`trueFalse`):**
```javascript
{
  id: "tf-new",
  question: "نص العبارة صحيحة أم خاطئة؟",
  answer: true, // أو false
  explanation: "التفسير العلمي."
}

```

## ✔️ قواعد التحقق من صحة الأمثلة الحسابية

عند إضافة أو تعديل أي أمثلة حسابية أو تحويلات عددية:

1. **التحويل العشري إلى ثنائي:** تأكد من أن بقايا القسمة المتكررة على 2 متطابقة مع قراءة البواقي صعوداً (من الأخير للأول).
2. **التحويل الثنائي إلى عشري:** تأكد من مطابقة مجموع حاصل ضرب أوزان القوى ($2^0, 2^1, \dots$) للناتج العشري النهائي.
3. **وحدات التخزين:** الالتزام الصارم بمعامل المضاعفة الحاسوبي الدقيق ($1 \text{ KB} = 1024 \text{ Bytes}$).
