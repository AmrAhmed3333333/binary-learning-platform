# Binary Learning Platform

Audience: First-secondary students and their teachers.
Language: Arabic.
Direction: RTL.
Stack: Next.js App Router, JavaScript/JSX, Tailwind CSS v4.

## Content rule
The teacher-provided lesson is the source of truth for curriculum scope.
Review the attachment before finalizing explanations, examples and assessments.

## Planned modules
1. Lesson overview and learning objectives.
2. Step-by-step explanation.
3. Interactive binary place-value simulator.
4. Worked examples and guided practice.
5. Formative quiz with explanatory feedback.
6. Teacher lesson plan and classroom activity.
7. Final assessment and review.
